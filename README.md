## 📌 使用教程
1.  安装 **NeoForge 47.0.2**（适配 MC1.21.1）
    - 官网下载：https://neoforged.net/
2.  启动一次游戏，自动生成 `.minecraft/mods` 文件夹
3.  将下载的 `infinitefuel-1.0.0.jar` 放入 `mods` 文件夹
4.  重新启动游戏，放置熔炉即可使用
