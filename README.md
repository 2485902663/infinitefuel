# 🔥 Infinite Fuel Mod（无限燃料模组）
适用于 **Minecraft 1.21.1 + NeoForge 47.0.2**，让煤炭/木炭在熔炉中无限燃烧，无需重复添加燃料！

## 📦 立即下载
[![Download JAR](https://img.shields.io/badge/Download-infinitefuel--1.0.0.jar-blue?style=for-the-badge&logo=github)](https://github.com/2485902663/infinitefuel/releases/download/v1.0.0/infinitefuel-1.0.0.jar)

## 📌 使用教程
1.  安装 **NeoForge 47.0.2**（适配 MC1.21.1）
    - 官网下载：https://neoforged.net/
2.  启动一次游戏，生成 `.minecraft/mods` 文件夹
3.  将下载的 `infinitefuel-1.0.0.jar` 放入 `mods` 文件夹
4.  重新启动游戏，放置熔炉即可使用

## ✅ 功能说明
- 煤炭/木炭放入熔炉后**永不消耗**
- 支持多熔炉并行工作，无卡顿
- 存档重启后功能正常保留
- 无冲突，兼容其他模组
