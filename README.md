# 🔥 Infinite Fuel Mod (无限燃料模组)
适用于 **Minecraft 1.21.1 + NeoForge**，让煤炭/木炭在熔炉中无限燃烧！

## 📦 立即下载
[![Download JAR](https://img.shields.io/badge/Download-infinitefuel--1.0.0.jar-blue?style=for-the-badge)](https://github.com/2485902663/infinitefuel/releases/download/v1.0.0/infinitefuel-1.0.0.jar)

## 📌 使用方法
1.  安装 **NeoForge 1.21.1** 启动器（[官网下载](https://neoforged.net/)）
2.  把下载的 `.jar` 文件放到 `.minecraft/mods` 文件夹
3.  启动游戏，将煤炭/木炭放入熔炉燃料槽，即可无限燃烧！
