# 🔥 Infinite Fuel Mod (无限燃料模组)
适用于 **Minecraft 1.21.1 + NeoForge**，让煤炭/木炭在熔炉中无限燃烧！

## 📦 直接下载
[**点击下载 infinitefuel-1.0.0.jar**](https://github.com/2485902663/infinitefuel/releases/download/v1.0.0/infinitefuel-1.0.0.jar)

## 📌 使用方法
1. 安装 **NeoForge 1.21.1** 启动器（[官网下载](https://neoforged.net/)）
2. 把下载的 `.jar` 文件放到 `.minecraft/mods` 文件夹
3. 启动游戏，放入煤炭/木炭到熔炉燃料槽即可无限烧！
